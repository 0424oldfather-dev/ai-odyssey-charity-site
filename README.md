# AI Odyssey Charity｜公益透明網站

奧德賽禪音 AI Odyssey 的六語系公益透明靜態網站。網站呈現商家核准佣金、50% 公益提撥、實際捐款及待捐結餘。

## 公開規則

- 正式起算日：2026-11-01（含當日）。
- 僅納入 YouTube Shopping 蝦皮聯盟商家正式核准且符合資格的佣金。
- 每筆合格核准佣金提撥 50%。
- 待捐餘額達 NT$1,000 時安排捐款；門檻不是捐款上限。
- 後續平台付款只供對帳，不重複提撥。
- 只有已完成付款的捐款才列入公開支出。

## 公開資料

前端只讀取同一個靜態網站內的 `data/public-snapshot.json`。目前檔案是經核准格式的空白狀態，不含虛構收益、測試成果或私人帳務。畫面依人工核准的公開快照更新，並顯示最後核准公開日期。

未來資料流程：

`私人表單 → 私人帳務 → 人工核准 → 公開安全 JSON → 本網站`

公開儲存庫不得加入私人表單、試算表、Apps Script 後端、OAuth 憑證、訂單資料、私人備註、收據或 Mock 財務成果。

## 人工核准快照更新流程

1. 在私人帳務端完成核對與人工核准，只匯出公開欄位。
2. 在公開站的獨立工作副本替換 `data/public-snapshot.json`；正式快照須將 `prelaunch` 設為 `false`，並以 UTC ISO 8601 格式填入 `publishedAt`。
3. 執行 `npm test`。前端會拒絕未知欄位、非法日期或金額、重複捐款編號、月報結餘錯誤，以及月報、捐款明細與總計不一致的快照。
4. 檢查 Git diff，確認只含核准的公開 JSON，且沒有訂單、備註、收據路徑、Google 資源識別或憑證。
5. Commit 並 Push 至 Private Repository。待複核通過後，再由 Owner 決定是否發布 GitHub Pages。

若任何檢查失敗，保留上一版已核准的 JSON，不應發布該次資料。
